# 논리집 데이터 EDA 시작

## 지금 확인할 것

**계산기에 쓸 이론적 분류를 확인하는 것**이 현재 EDA의 목적입니다(2026-11-06 사용자 결정).
작업의 어떤 성질이 왜 턴 수·처리 속도·맥락 크기에 영향을 주는지 살펴보고,
기존 분류와 계산 조각이 실제 기록에 맞는지 확인합니다.
빈도나 전체 적중률만으로 분류가 타당하다고 결론 내리지는 않습니다.
탐색에서 얻은 분류는 가설로 두고 이후 기록으로 시험합니다.
논문 비교 방향은 [아이디어 메모](../docs/agent-usage-research-ideas.md)에 따로 기록했습니다.

관찰과 나중에 확인할 그래프는 [2026-11-06 EDA 보고서](report-2026-11-06.md)에 이어서 기록합니다.

## Colab에서 시작

저장소 루트에서 Python 3.11 이상으로 실행합니다. 파일 준비에는 추가 패키지가 필요 없습니다.

```console
python -m eda.colab
```

`out/eda_colab/`에 두 파일이 생깁니다.

1. `proviso_eda_colab.ipynb`를 Colab의 **파일 → 노트북 업로드**로 엽니다.
2. CPU 런타임에서 첫 코드 셀을 실행하고 `proviso_eda_data.zip`을 선택합니다. ZIP은 풀지 않습니다.
3. 표 11개의 행·열 수가 보이면 준비 완료입니다. 여기서 결과를 확인한 뒤 분석 셀을 하나씩 실행합니다.
4. 그래프를 보기 전 한글 글꼴 셀을 실행합니다.

데이터는 ZIP을 만든 시점의 스냅샷입니다. 원본이 바뀌면 위 명령으로 다시 만들고,
Colab에 있던 `proviso_eda_data.zip`을 지운 뒤 새 ZIP을 올립니다.
생성 시각·원본 커밋·미커밋 변경 여부·CSV별 행 수와 SHA-256을 함께 기록합니다.
분석 셀은 기존 `start.ipynb`에서 가져옵니다.

## 로컬에서 시작

```console
python -m pip install -r eda/requirements.txt
python -m jupyterlab eda/start.ipynb
```

처음에는 분야별 노드 수, 작업 기록의 실측 유무, 피드백 출처부터 확인합니다.
`far_fields`는 AI가 생성한 대량 조각이므로 다른 분야와 분리해서 봅니다.
원본 지식 파일은 읽기만 하고 내보낸 데이터와 노트북 출력은 `out/`에 둡니다.
