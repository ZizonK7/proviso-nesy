# 연결 실험 v0 — 무작위 두 조각 잇기

- 작성: 2026-11-03, Claude(메인). 사용자 원칙은 부모 세션(잼민이)이 옮긴 2026-11-03 사용자 말.
- 재료: [domains/far_fields](../domains/far_fields/CLAUDE.md)의 먼 분야 조각. 코드: `python -m domains.far_fields.connect <쌍 수> <seed>`.
- 기록: [docs/experiments/connections/](experiments/connections/) (seed마다 파일 하나).

## 왜
사용자: 창의성은 기존 논리를 생각지 못한 방식으로 잇는 과정이다. 창의적인 생각이 필요하면 논리집에서 아무거나 뽑아 이어 본다. 말도 안 돼 보이는 연결도 충분히 고민한다(배제하면 스스로 창의성을 막는다). 충분히 고민했는데도 안 되면 우리 사고력이 부족한 것이니 포기한다. 포기한 연결은 지우지 않고 "어디까지 해 봤는지"와 함께 남긴다(잼민이 제안).

## 절차
1. **뽑기**: 살아 있는 조각 가운데 둘을 `random.Random(seed)`로 뽑는다. 같은 묶음(바다·불·동물 같은 큰 갈래)이거나 같은 모양(조건 상태)을 하나라도 공유하면 다시 뽑는다 — 같은 모양이면 이미 그래프로 이어져 있어 '생각지 못한' 연결이 아니다. seed를 적어 두면 같은 쌍이 다시 나온다.
2. **다시 말하기**: 두 조각을 조건 → 결론 → 이유로 다시 쓴다. 일반화 문장이 흐리면 여기서 드러난다.
3. **네 각도 모두 시도** ('충분히 고민'을 숫자로 정한 것): 옮기기(A의 방법을 B에, B를 A에) · 같은 뼈대(이유까지 같은 구조인가) · 부딪히기(둘이 다른 행동을 권하는 상황) · 잇기(A의 결과가 B의 조건). 각도마다 시도문과 되었나/막힌 이유를 반드시 쓴다. 한 각도만 해 보고 포기하지 않는다.
4. **새 조각 또는 포기**: 된 연결 가운데 가장 나은 것 하나를 분야 이름 없는 조각으로. 두 조각 중 하나를 다시 말한 것이거나 '균형이 중요하다' 같은 뻔한 말이면 연결이 아니라 포기로 적고, 어디까지 해 봤는지 남긴다.
5. **사용자 생활에 대 보기**: 새 조각이 사용자 생활(수능 수학 과외, 학원 상담, 데이터 과학 공부, AI 에이전트에게 일 맡기기)에서 무엇을 바꾸는지 하나. 억지면 억지라고 쓴다.
6. **평가 둘**: 모델 자기평가(새로움·쓸모·억지 1~5)는 참고만. 판정은 **사용자**가 한다 — 쓸모 있는 생각인지는 사용자 실사용만 가를 수 있다(루트 CLAUDE.md '판단의 기준은 사용자 실사용 경험'). 사용자가 쓸모 있다고 한 새 조각만 그 분야(사용자 생활 쪽) 논리집에 가설로 넣는다.

## 지킬 것
- 포기도 기록이다. 파일에서 지우지 않는다.
- 새 조각은 근거가 두 AI 조각뿐이므로 가장 가벼운 출처(AI 판단)에서 시작한다.
- 지금은 연결을 Opus 5.5 한 번 호출로 한다. 사람이 같은 쌍을 직접 해 보고 비교하는 것, 같은 쌍을 여러 번 돌려 흔들림을 보는 것은 아직 안 했다.

## 열린 문제
- 무작위가 정말 좋은가: 모양을 하나도 공유하지 않는 쌍만 고르면 너무 먼 쌍이 많아 포기가 늘 수 있다. 모양 하나만 공유하는 쌍과 비교해 볼 것.
- 자기평가의 '새로움'은 믿기 어렵다(자기 생각을 높게 치는 경향). 사용자 판정이 쌓이면 자기평가와 얼마나 맞는지 본다.
- 사용자 원칙의 "나중에는 모든 일에 그렇게 생각해 볼 수도"는 아직 설계 밖. 결정마다 무작위 조각 하나를 대 보는 절차가 후보.
