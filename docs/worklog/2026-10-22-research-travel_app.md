## 확인한 것 (어떻게)
- 웹 검색(WebSearch) 20회. 검색 요약으로 기능·평점·가격 정보를 모았다.
- 본문을 직접 읽은 곳(WebFetch): 위키백과 영문판 Splitwise, Google Lens, Suica, Papago(동음이의 페이지, 정보 없음). 위키백과 페이지는 열렸고 나머지 대부분의 사이트는 열리지 않았다.
- 연결 확인: curl로 호스트별 상태 코드를 확인했다. 위키백과만 200 또는 301로 응답했다. 나머지는 연결 실패(000)였다.
- 근거 강도는 대부분 "약"으로 매겼다. 메타분석, 통제 연구, 대규모 데이터는 찾지 못했다.

## 확인 못 한 것
- 앱스토어 원문 리뷰와 평점: 모든 앱스토어 페이지가 열리지 않았다. 평점은 검색 요약 숫자다.
- 공식 사이트: JR동일본(Welcome Suica), Tricount, Visit Japan Web 공식 페이지를 열지 못했다.
- 한국어 실사용 후기(블로그, 카페, 네이버): 검색에서 거의 나오지 않았다. "네일동"은 찾지 못했다.
- Reddit r/JapanTravel: 연결 실패, 검색으로도 게시글을 찾지 못했다.
- 가격·무료 제한: 자료마다 다르고 날짜가 불명확하다. 현재 값으로 확정할 수 없다.
- 후보 17(Travel Manager 논문)은 요약만 확인했다.

## 알려진 문제
- 막힌 곳: pilotplans.com은 이름 해석 실패(WebFetch 2회)이고 프록시가 CONNECT 403을 돌려줬다. 정책 차단으로 보여 재시도하거나 우회하지 않았다. apps.apple.com, jreast.co.jp, tricount.com, reddit.com은 연결 실패였다.
- 근거 질: 전체적으로 약하다. 기능 설명은 개발사 주장과 검색 요약에 의존한다. 보고서의 확신도 표기를 그대로 믿지 말고, 원문 확인 후 올리는 것이 좋다.
- 상충 자료가 여럿 있다(Splitwise 가격·무료 제한, Tricount 평점, Welcome Suica 유효기간, Settle Up 광고 여부, 토스 차등 정산). 보고서 "각도 요약"에 정리했다.
- 서로 다른 앱에 있는 기능은 하나로 묶지 않았다. 일본 특화 기능을 가진 정산 앱은 확인되지 않았다.
