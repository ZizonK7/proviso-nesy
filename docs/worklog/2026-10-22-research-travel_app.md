## 확인한 것 (어떻게)
- 웹 검색(WebSearch) 20회. 검색 요약으로 기능·평점·가격 정보를 모았다.
- 본문을 직접 읽은 곳(WebFetch): 위키백과 영문판 Splitwise, Google Lens, Suica, Papago(동음이의 페이지, 정보 없음). 위키백과 페이지는 열렸고 나머지 대부분의 사이트는 열리지 않았다.
- 연결 확인: curl로 호스트별 상태 코드를 확인했다. 위키백과만 200 또는 301로 응답했다. 나머지는 연결 실패(000)였다.
- 근거 강도는 대부분 "약"으로 매겼다. 메타분석, 통제 연구, 대규모 데이터는 찾지 못했다.

## 확인 못 한 것
- 앱스토어 원문 리뷰와 평점: 모든 앱스토어 페이지가 열리지 않았다. 평점은 검색 요약 숫자다.
- 공식 사이트: JR동일본(Welcome Suica), Tricount, Visit Japan Web 공식 페이지를 열지 못했다.
- 한국어 실사용 후기(블로그, 카페, 네이버): 검색에서 거의 나오지 않았다. "네일동"은 찾지 못했다.
- Reddit r/JapanTravel: 연결 실패, 검색으로도 게시글을 찾지 못했다.
- 가격·무료 제한: 자료마다 다르고 날짜가 불명확하다. 현재 값으로 확정할 수 없다.
- 후보 17(Travel Manager 논문)은 요약만 확인했다.

## 알려진 문제
- 막힌 곳: pilotplans.com은 이름 해석 실패(WebFetch 2회)이고 프록시가 CONNECT 403을 돌려줬다. 정책 차단으로 보여 재시도하거나 우회하지 않았다. apps.apple.com, jreast.co.jp, tricount.com, reddit.com은 연결 실패였다.
- 근거 질: 전체적으로 약하다. 기능 설명은 개발사 주장과 검색 요약에 의존한다. 보고서의 확신도 표기를 그대로 믿지 말고, 원문 확인 후 올리는 것이 좋다.
- 상충 자료가 여럿 있다(Splitwise 가격·무료 제한, Tricount 평점, Welcome Suica 유효기간, Settle Up 광고 여부, 토스 차등 정산). 보고서 "각도 요약"에 정리했다.
- 서로 다른 앱에 있는 기능은 하나로 묶지 않았다. 일본 특화 기능을 가진 정산 앱은 확인되지 않았다.

## 이어서: 원문 확인 (2026-10-22, 네트워크 개방 뒤)

- 방법: WebFetch 도구는 프록시를 타지 않아 이름 해석에 실패했다. curl(프록시 경유)로 페이지를 받아 pandoc으로 본문을 뽑아 읽었다. 앱 스토어 평점은 페이지 안 구조화 데이터(ratingValue, reviewCount)에서 읽었다. 한글 PDF는 pypdf로 뽑은 뒤 깨진 글자(cp949)를 되돌려 읽었다.
- 원문 확인 수: 약 57곳(앱 스토어 17, 플레이 스토어 7, 공식 사이트·문서 10, 기사·리뷰 16, 네이버 블로그 6, 학술 PDF 1). 보고서 0절 "이어서" 소절에 목록.
- 바뀐 수치·판정 (주요 14건):

  2. Splitwise: iOS 4.0/29K, Android 4.3/19.5만. 공식 Pro 가격 월 $2.99·$4.99, 연 $39.99(Pilot은 연 $29.99). 무료 하루 상한은 공식에 숫자 없음, 리뷰 3~5건. CSV 내보내기·오프라인 입력·여러 결제자는 무료(공식). 근거 강도 약→중, 확신도 중간→높음.
  3. Tricount: iOS 4.9/7.5K, Android 4.8/19.6만. 공식 FAQ "거래 횟수 제한 목표" 확인. 현재 앱 내 구입 없음·"구독 없음" 대 Pilot(2025-12) 연 $10 프리미엄·Play "광고 포함" 라벨 — 새 상충. Trustpilot 3.3은 확인 못 함. 근거 강도 약→중.
  4. 트리플: 2026-11-03 서비스 종료, NOL 통합(앱 스토어 설명). 적용 판정 일부→아니오. 가계부에 결제자·동행 표시가 있었음(버전 기록).
  5. 구글 지도: 2018 Engadget의 "덜 정확" 문장은 필리핀 이야기 — 1차 오독 정정. 일본 평가는 긍정. 하니서울 가이드의 "플랫폼 번호·빠른 칸·신주쿠" 주장은 원문에 없음.

  7. 파파고: 14개 언어(13개 아님), 오프라인은 텍스트 번역만. iOS 4.7/3.5K, Android 4.6/17.9만.
  8. NAVITIME: iOS 4.7/2.6K, Android 4.7/1.4만. "개인정보 점수 57/100"은 확인 못 해 뺌. Check & Ride(전광판 사진 확인), IC 카드 NFC 잔액 확인 기능 추가.
  9. 토스 모임 정산: 공식 글에서 "토스 앱 없어도 링크로 내역 열람" 확인(새 기능 근거). 비교 글과의 상충은 유지.
  10. 트래블로그: 운영사 인터뷰에서 "여행 로그" 기록 기능 확인(1차 "모름"→일부). ATM 수수료 자료 상충 추가.
