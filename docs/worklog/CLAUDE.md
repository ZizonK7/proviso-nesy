# docs/worklog/ — 하위 에이전트 작업 보고서

하위 에이전트는 작업 하나가 끝날 때마다 여기 보고서를 하나 남긴다. 이름: `YYYY-MM-DD-<주제>.md`.
(batman 저장소의 worklog 방식을 가져옴, 2026-10-14)

## 양식

```markdown
# YYYY-MM-DD — <주제>

에이전트: <역할> (모델, effort). 하위 에이전트 호출: 없음 / 있으면 목록(주제, 모델, effort, 난이도, 예상).
커밋·push: 안 함 / 지시서가 허용해서 함(커밋 해시).

## 한 일
- 만들거나 바꾼 파일과 그 내용. 지시서를 넘어서 한 일은 따로 표시.

## 확인한 것 (어떻게)
- 실제로 돌린 정확한 명령과 결과. 예: `python -m unittest discover -s tests -t .` → 24개 통과.

## 확인 못 한 것
- 돌려 보지 않았거나 돌릴 수 없었던 것. 확인하지 않은 건 확인했다고 쓰지 않는다.

## 알려진 문제
- 남아 있는 버그, 빈틈, 임시방편.

## 다음 작업자에게
- 이어받는 사람이 알아야 할 것, 추천하는 다음 단계, 피해야 할 함정.
```

## 규칙
- 보고서는 다음 작업자(사람이든 모델이든)가 이것만 읽고 이어받을 수 있게 쓴다.
- 사용자 개인정보·비밀값은 넣지 않는다(공개 저장소).
- 그림이 필요하면 `img/`에 PNG로, 한 장 500 KB 이하.
