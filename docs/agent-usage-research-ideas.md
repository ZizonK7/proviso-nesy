# 에이전트 자원 예측 — 논문 아이디어

기록일: 2026-11-06. 출처: 사용자와 EDA 중 나눈 대화.
상태: 나중에 검토할 아이디어. 연구 기여나 효과가 확인된 결과가 아니다.

## 현재 작업과의 관계

사용자 결정: 지금 EDA의 목적은 **계산기에 쓸 이론적 분류를 확인하는 것**이다.
논문 방향을 고르거나 논문용 비교 실험을 설계하는 일은 현재 EDA의 목표로 삼지 않는다.

## 관찰과 질문

- 사용자 관찰: 이전에는 에이전트의 소요 시간 예측이 크게 빗나갔는데, 실제 사례와 피드백이 쌓인 뒤 적중률이 높아 보인다. 아직 통제된 비교 결과는 아니다.
- 설명 후보: 과거 실측을 기준점으로 삼고, 이번 작업의 차이를 피드백과 규칙으로 보정하기 때문에 예측이 개선되는가?
- 추가 질문: 과거 사례를 그대로 제공하는 것보다, 실패에서 뽑은 조건부 피드백이 새로운 작업의 예측을 더 개선하는가?
- '기존 LLM은 사람 기준으로 예측해서 틀린다'는 설명은 검증되지 않았다.

## 나중에 비교할 후보

같은 새 작업과 같은 예측 모델에서 다음 조건을 비교한다.

1. 기록 없이 예측.
2. 과거 실측 사례만 제공.
3. 과거 실측 사례와 정돈된 피드백·백서를 함께 제공.

중앙값, 유사 작업 검색, 간단한 회귀모형도 비교 대상으로 검토한다.
사례의 효과와 정돈된 피드백의 추가 효과를 구분하고, 새로운 작업 종류에서도 효과가 있는지 확인한다.
예측 전에 알 수 있었던 자료만 쓰고, 같은 맥락 분량·예측 비용에서의 비교도 고려한다.

예측 대상 후보는 시간, 입력·출력·캐시를 구분한 토큰, 측정 가능한 사용량이다.
사용량은 API 비용·도구 호출 수 등으로 뜻을 구체적으로 정한다.
구간 적중률뿐 아니라 구간 폭, 실제 값과의 오차, 예측 자체의 비용을 함께 본다.
평가 대상을 늘리는 것만으로 새로운 연구 기여가 생긴다고 보지는 않는다.

## 관련 연구 메모

2026-11-06에 초록을 확인한 관련 연구. 체계적인 선행연구 조사는 아직 하지 않았다.

- [How Do AI Agents Spend Your Money?](https://arxiv.org/abs/2604.22750): 에이전트 코딩 작업의 토큰 소비와 실행 전 자기 예측을 분석한다.
- [TokenCast](https://arxiv.org/abs/2609.35760): 실행 중 관찰을 이용해 토큰 소비 예측을 갱신한다.
- [Reflexion](https://arxiv.org/abs/2303.11366): 자연어 피드백을 기억해 이후 시도의 의사결정에 활용한다.

자원 소비 예측이나 자연어 피드백의 축적 자체를 새 기여로 가정하지 않는다.
논문 검토를 재개할 때 위 연구의 본문·실험과 실제 차이를 확인한다.
