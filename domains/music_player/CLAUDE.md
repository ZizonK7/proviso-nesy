# domains/music_player/ — 뮤직 플레이어 '알아서 틀기'

사용자의 앱 music_player(github.com/ZizonK7/music_player, 비공개)의 알아서 틀기 폴더에 대한 지식. 본체 실험 v0 질문 1을 조각으로 다시 분석하면서 만들었다(2026-10-14).

- 앱 동작(사실)은 사용자에게 묻지 말고 `src/js/smart.js`와 `DECISIONS.md`에서 확인한다. 사실 노드에는 확인한 커밋을 적는다.
- **의도와 동작의 차이 (2026-10-14)**: 사용자 의도는 "알아서 틀기에서 같은 곡이 나오면 안 된다(다양성)". 실제로는 직전 10곡 안에서만 중복을 막고, 대기열은 처음 30곡 뒤 20곡씩 끝없이 이어 붙는다(`app.js` extendSmart) → 같은 곡이 다시 나온다. `audit`이 F_dup_window로 잡는다.
- 사용자 결정: "최대 30곡, 한 번씩만"(R_M1b). 기존 설계 "끝이 없다"와 충돌 → 30곡 뒤 처리 방식 확인 대기. 확인 후 music_player main에 push(사용자 요청). 로컬 클론은 이 PC에 없음.
- 비공개 저장소의 코드를 옮겨 적지 않는다. 동작을 문장으로 요약만.
