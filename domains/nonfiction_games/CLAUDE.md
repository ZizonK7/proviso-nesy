# domains/nonfiction_games/ — 비문학 기반 게임의 성공 논리

잘 된 게임(특히 책·논문·기록이 바탕인 것)의 성공 논리를 쪼개, 비문학에 대 볼 수 있게 하는 논리집. 2026-10-19에 만들었다.
배경과 사례 조사: [docs/nonfiction-games-v0.md](../../docs/nonfiction-games-v0.md). 방향과 사용자 결정은 루트 CLAUDE.md "새 방향".

## 출처 규칙
- **사실**: 원문에서 확인한 것만(위키백과 원문, 개발자 발언, 제작자 페이지, Steam 숫자). `checked` 날짜와 `source`를 붙인다. 게임 동작도 사실이다 — 사용자에게 묻지 않고 출처에서 확인한다.
- **관찰**: 사용자가 그 게임을 하며 겪은 것(사용자 결정: 해 본 게임은 사용자 판단이 기준). 해 보지 않은 게임은 대중·전반 평가를 관찰로 쓰고 `source`에 그렇게 적는다.
- **가설**: AI가 사실에서 뽑은 설명(`source = "ai"`). 성공 사례만 보고 세운 **사후 설명**이다 — 사용자 경험과 망한 사례에 대 보기 전에는 규칙으로 올리지 않는다.

## 순서 (사용자 결정 2026-10-19)
성공 사례로 논리를 먼저 세운다 → 망한 게임에 대 본다 → 피드백으로 더 쪼갠다. 넓히기 전에 조사 보고서의 게임들로 먼저 만든다.

## 현재 상태 (2026-10-19)
- 심즈(사용자가 해 본 유일한 게임)부터: 사실 8개(원문 확인), AI 가설 4개. 사용자 경험(관찰)을 받기 전이라 규칙은 없다.
- 다음: 사용자 경험으로 가설을 지지·반박 → 규칙(가설 상태) → 다른 게임(SimCity, This War of Mine 등은 대중 평가로).
