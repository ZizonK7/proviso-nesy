# 메인 피드백 — 그림 · 스크린샷 · PDF · 글꼴 · 렌더
키워드: 그림, 스크린샷, 이미지, PDF, 글꼴, 렌더, 캡처
읽는 때: 그림을 받아 보게 하거나, PDF를 읽히거나, HTML→PNG/PDF 렌더가 있는 일을 보내기 전.

- **F025** 그림이 필요하면 "그림 파일을 받아 Read로 본다"와 받는 주소 패턴(스토어 `play-lh.googleusercontent.com/...=w1000`)을 적는다. 홍보용 합성 목업은 '강' 근거에서 뺀다 — '설명'을 요구하면 글만 읽는다. (사용자 질문 → 실측, 2026-10-22)
- **F072** 여러 쪽짜리 새 입력(PDF·노트)은 메인이 한 쪽을 먼저 열어 본다 — 획 순서가 섞인 4쪽을 보내고 나서 알았다. (실측, 2026-11-05)
- **F075** 글꼴이 필요한 렌더는 Google Fonts 파일을 curl로 받아 로컬로(Noto Serif/Sans KR 434KB). 안 되면 "대체 글꼴"을 보고서 맨 위에 적고 PC 재렌더를 할 일로. (실측, 2026-11-02·05)
- **F113** 축소판은 배치 확인용이다. 내용 오류·불필요한 코드라고 판단하기 전에 해당 쪽을 확대하고 원본 텍스트/HTML과 대조한다. (실측, 2026-11-07)
- **F114** 로컬 PDF의 글꼴·수식 로딩 검증은 작업 범위로 제한한 loopback HTTP 렌더에서 실패 요청·HTTP 오류·실제 사용 글꼴·PDF 임베딩을 함께 확인한다. (실측, 2026-11-07)
