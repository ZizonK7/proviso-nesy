# 메인 피드백 — 병렬 작업자 · 이어 보내기 · 팀
키워드: 병렬, 동시, worktree, 이어보내기, 회차, 팀, 담당
읽는 때: 작업자를 둘 이상 동시에 보내거나, 같은 에이전트에 이어 보내거나, 담당 + 팀원 구조를 쓰기 전.

- **F038** 임시 파일은 "내 이름 붙은 하위 폴더에만", 다른 작업자의 폴더는 "복사해서만" — 공유 scratchpad에서 같은 이름을 덮어썼다. (실측, 2026-10-27)
- **F039** 같은 저장소에 둘 이상 보내면 각자 git worktree. 지시서에 '건드릴 파일·함수·절'을 팀별로 적는다 — 같은 트리에서는 읽는 쪽 숫자도 흔들렸고, worktree에서는 충돌 0. (실측, 2026-10-20·11-04)
- **F042** 같은 에이전트 이어 보내기는 시간은 아끼지만 토큰은 회차마다 커진다(20회차 넘기면 턴당 맥락 50만). 다음 세션은 새 에이전트로. (실측, 2026-11-05)
- **F043** 끊긴 회차는 `status = "stopped"`, 새 에이전트에 diff '대조 → 채우기'로 이어 준다(1회차 토큰의 2/3). 큰 구현은 두 회차로 나누는 것을 생각한다. (실측, 2026-11-04)
- **F044** 팀 = 담당 하나 + 팀원. 담당이 대조·종합하고 메인은 종합만 받는다 — 메인이 직접 받으면 진행 이벤트까지 맥락에 들어온다. (사용자 지시 + 실측, 2026-11-05)
