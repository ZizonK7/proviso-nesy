# 메인 피드백 — 검토 · 비평
키워드: 검토, 비평, 반영, 검수
읽는 때: 글·풀이·설계를 내보내기 전 검토를 짜거나, 비평 결과를 반영할 때.

- **F041** 반영 점검은 새 에이전트보다 같은 비평가에게 이어서(시간·턴 반). 조사와 비평은 순서가 아니라 병렬 + 2회차. (실측, 2026-10-27)
- **F047** 내보내기 전에는 새 눈(새 에이전트, xhigh)의 검토 한 바퀴 — 네 번 연속 메인이 못 본 수학·표현 오류를 잡았다(장당 1.5–3분). 메인은 이미 닻이 내려 있다. (사용자 제안 + 실측, 2026-11-02~05)
- **F048** 반영표는 비평 번호 전체로 기계적으로 만든다(빈 칸이 보이게) — 손으로 만들어 한 행이 빠졌다. (실측, 2026-10-29)
