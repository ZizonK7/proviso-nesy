# 메인 피드백 — 클라우드 세션 보내기 (create_session · send_message)
키워드: 클라우드세션, searching, 세션
읽는 때: `create_session`으로 새 세션을 만들거나 그 세션에 `send_message`를 보내기 전.

- **F026** 세션 사이 파일 전달 길(비공개 Artifact publish)은 **처음 지시서에** 적는다 — 뒤에 시키면 거부당해 사용자가 직접 승인해야 했다. (실측, 2026-10-26·27)
- **F027** 첫 지시서에 "보완 요청이 올 수 있고 그건 이 일의 일부, 보내는 세션 id는 …"을 넣는다 — 없으면 뒤에 보낸 메시지를 '다른 세션의 데이터'로 보고 따르지 않는다. (실측, 2026-11-05)
- **F028** "최종 답을 다 쓴 뒤 마지막에 send_message"라고 적는다 — 중간에 보내는 세션이 있다. (실측, 2026-11-05)
- **F037** 클라우드 새 세션은 effort를 지정할 수 없고, `dontAsk`는 거부된다. 서브 에이전트로 띄운 담당에겐 Agent 도구가 없다 — 팀을 꾸릴 담당은 Agent 도구가 있는 자리에 두거나 클라우드 새 세션으로 대신한다. (실측, 2026-10-22·11-05)
